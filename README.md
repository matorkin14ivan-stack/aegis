# AeGIS — запуск на GitHub Pages

Готовый лендинг на HTML, CSS и JavaScript. Для запуска не нужны сборка и установка зависимостей.

## Загрузить и запустить

1. Распакуйте **AeGIS_GitHub_Pages.zip**.
2. Создайте репозиторий на GitHub, например **aegis-website**. Для бесплатного GitHub Pages выберите **Public**.
3. Нажмите **Add file → Upload files**. Загрузите содержимое распакованной папки, сохранив папки и названия файлов. Загружайте файлы, а не ZIP.
4. **index.html** должен находиться в корне репозитория, рядом с **styles.css**, **app.js** и **assets/**. Не вкладывайте весь сайт в дополнительную папку.
5. Нажмите **Commit changes** и сохраните файлы в ветку **main**.
6. Откройте **Settings → Pages**. Выберите **Source: Deploy from a branch**, **Branch: main**, папку **/(root)** и нажмите **Save**.
7. После публикации ссылка появится в **Settings → Pages**. Пример адреса: `https://YOUR-USERNAME.github.io/aegis-website/`.

Файл `.nojekyll` включён в архив. Если система скрывает его при загрузке, создайте в корне репозитория пустой файл с этим именем через **Add file → Create new file**.

## Файлы

- **index.html** — содержимое и форма.
- **styles.css** — оформление и адаптация под экраны.
- **app.js** — отправка заявки и состояния формы.
- **assets/** — изображения и веб-шрифты.
- **font-sources/** и **licenses/** — исходные файлы и уведомления для шрифтов.
- **.nojekyll** — публикация статических файлов.

Все пути относительные: сайт работает и в корне домена, и по адресу с названием репозитория.

## Форма заявок

В **index.html** уже установлен ключ:

```html
<input type="hidden" name="access_key" value="32f2463a-a591-4bb7-afb4-9b7b54aab930">
```

Имя и телефон отправляются через Web3Forms без перезагрузки страницы. Получатель — email, к которому зарегистрирован ключ. Дополнительные получатели в коде не настроены.

При отправке кнопка блокируется и показывает **Sending...**. Успешный ответ сервиса вызывает зелёное сообщение и очистку полей. При ошибке появляется красное сообщение, данные сохраняются.

После запуска отправьте заявку со своим именем и телефоном и проверьте входящие и папку «Спам». Доставка ранее не проверялась реальной отправкой.

## Изменять сайт

Правьте текст в **index.html**, оформление — в **styles.css**. После сохранения изменений в **main** GitHub Pages публикует обновление.
